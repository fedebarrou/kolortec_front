# Kolortec — cotización del sitio web

14 de octubre de 2026

## El precio

El desarrollo del sitio kolortec.com.ar tiene un valor de mercado de $5.500.000. Para Kolortec, por contratar el abono mensual de soytiendita, queda en **$1.500.000**, por única vez.

Incluye el diseño, el desarrollo, la intro cinematográfica, el modelo 3D, las dos versiones de idioma, el SEO, la conexión con el panel y la puesta en producción. El uso mensual de soytiendita, que es el panel desde el que se administra el sitio, se cobra aparte con el abono.

## Qué tiene el sitio

kolortec.com.ar no es una página institucional: es un sitio de marca completo, bilingüe y autoadministrable, con más de 20 secciones, animaciones de nivel premium y todo el contenido manejado desde un panel.

| Área | Qué incluye |
| --- | --- |
| Diseño | Identidad visual propia negro y amarillo, diseñada a medida y presentada con opciones que eligió Kolortec. Versiones para computadora y celular |
| Experiencia de entrada | Intro cinematográfica con scrollytelling: un video que avanza cuadro a cuadro con el scroll, con mensajes de marca sincronizados, versión propia para celular y botón para saltear |
| Modelo 3D | El HOT SPOT CMY en 3D con animación de despiece, optimizado para web |
| Portada | Carrusel editable desde un editor visual, con efectos, capas y oscurecido |
| Catálogo | Líneas y categorías, fichas de producto con galería, videos, especificaciones, innovaciones y precios que se pueden mostrar u ocultar |
| QR por producto | Cada producto tiene un QR fijo que lleva a su página de descargas |
| Centro de soporte | Manuales y librerías descargables, biblioteca de guías de mantenimiento, garantías y contacto |
| Comercial | Distribuidores, programa de alquiler y producción, servicios y «Sumate» |
| Clientes | Acceso con Google para descargas protegidas y «Mis datos» |
| Redes y contacto | Feed de Instagram, botón de WhatsApp, formulario de contacto |
| Idiomas | Español e inglés completos (432 textos traducidos) |
| Legales | Términos, privacidad y avisos legales |
| SEO | Cada página pre-generada para Google, metadatos propios, sitemap, dominio canónico y preparación para buscadores con IA |
| Rendimiento | Imágenes de 98 MB reducidas a 1,5 MB y 48 % menos de código inicial |
| Panel | Todo el contenido se administra sin programar: productos, guías, portada, galería, marcas, contactos, publicación y vista previa privada |

El desarrollo llevó seis meses de trabajo iterativo, de abril a octubre de 2026: se presentaron variantes, Kolortec eligió y se ajustó sobre la marcha.

## Cómo se compara con el mercado

El precio está en la franja de un sitio a medida premium: arriba de un sitio corporativo común, por todo lo que este trae de más.

| Referencia en Argentina, 2026 | Rango |
| --- | --- |
| Sitio corporativo autoadministrable | $1.000.000 a $3.000.000 |
| Sitio de 6 a 20 páginas en estudio chico | $1.400.000 a $4.600.000 |
| Sitio a medida | desde $4.000.000 |
| **Valor de mercado de este sitio** | **$5.500.000** |

Un sitio corporativo común no trae intro cinematográfica, modelo 3D, dos idiomas, catálogo con descargas por QR ni páginas pre-generadas para Google. Cada una de esas partes suele cotizarse aparte.
